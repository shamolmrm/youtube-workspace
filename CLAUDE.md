YouTube content work using the youtube-agent skill pack (github.com/Jakeschincariol/youtube-agent-skill, MIT),
installed project-local in `.claude/skills/yt-*`.

- The owner communicates in Bengali/Banglish; reply in Bengali.
- On this Windows machine `python3` / `python` are not available — run the skill tools with `py`
  (e.g. `py hookscore.py --hook "..."`).
- Voice profile: `~/.claude/youtube/voice.md` (template in `templates/voice.md`).
- Nothing gets published automatically — the owner uploads.
- Kids content: mark videos "Made for Kids" on YouTube; never copy existing characters, shows or songs.
